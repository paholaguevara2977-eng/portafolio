💻 Mi primer día con HTML

Aprendí que una página web es solo texto con estructura. Fue sencillo y muy satisfactorio ver mi nombre en pantalla.

Detalle completo: escribí un archivo .html, lo guardé con extensión UTF-8 y lo abrí en el navegador. Aprendí también la diferencia entre <head> y <body>, y por qué conviene usar UTF-8 para ver bien los acentos y los emojis.

🎨 Diseñando con CSS

El CSS le da vida a la página: colores, tipografías, espaciados y bordes redondeados.

Detalle completo: aprendí sobre selectores de clase, el modelo de caja con box-sizing: border-box y cómo los degradados con linear-gradient dan un aspecto profesional. También las media queries para que se vea bien en el celular.

🚀 Mi opinión sobre JavaScript

Con JavaScript una página deja de ser estática y empieza a responder al usuario.

Detalle completo: desde addEventListener y el event hasta manipulating el DOM con querySelector. Me gusta que el navegador sea el entorno donde se ejecuta el código, sin instalar nada.
